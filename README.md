# 아르떼 상담계약 — 안드로이드 앱

도면 인터랙티브 + 사진 + 견적/계약서가 들어 있는 앱입니다.
사진 211장과 도면이 앱 안에 들어 있어 인터넷 없이 돌아갑니다.

## APK 받는 법 (설치 프로그램 필요 없음)

1. 깃허브에 새 저장소를 만들고 이 폴더 전체를 올립니다.
   (웹에서 `Add file > Upload files` 로 폴더째 끌어다 놓아도 됩니다)
2. 올리면 **Actions** 탭에서 `APK 만들기` 가 저절로 돌아갑니다. 3~5분 걸립니다.
3. 초록 체크가 뜨면 그 실행을 눌러 맨 아래 **Artifacts > arte-apk** 를 받습니다.
4. 압축을 풀면 `app-debug.apk` 와 `app-release.apk` 가 나옵니다.
   둘 다 설치됩니다. 보통 `app-release.apk` 를 쓰면 됩니다.

안 돌아가면 Actions 탭에서 `APK 만들기` > `Run workflow` 를 직접 누르세요.

## 폰·태블릿에 설치

APK 파일을 안드로이드 기기로 보내고(카톡·메일·USB 아무거나) 눌러서 설치합니다.
처음에는 "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나옵니다. 허용하면 됩니다.

## 앱에서 달라지는 것

- 계약서를 만들면 **다운로드 > 아르떼계약서** 폴더에 엑셀과 이미지가 저장됩니다.
- 가로로 두면 사진·도면·견적 세 칸이 함께 보입니다.
- 자필 서명은 손가락과 스타일러스 모두 됩니다.

## 내용 바꾸기

`app/src/main/assets/index.html` 이 앱 화면 전체입니다.
웹에서 쓰던 그 파일이니, 새 파일로 바꿔 올리면 Actions 가 새 APK 를 만들어 줍니다.
버전을 올리려면 `app/build.gradle` 의 `versionCode` 와 `versionName` 을 고칩니다.
