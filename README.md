# 아르떼 상담계약 — 안드로이드 앱

도면 인터랙티브 + 사진 211장 + 견적/계약서가 한 앱에 들어 있습니다.
사진과 도면이 앱 안에 담겨 있어 인터넷 없이 돌아갑니다.

---

## 1. APK 받기

APK는 깃허브가 자동으로 만들어 줍니다. 컴퓨터에 아무것도 설치할 필요 없습니다.

1. https://github.com/pina-web/arte-android/actions 로 들어갑니다.
2. 왼쪽에서 **APK 만들기** 를 고르고, 맨 위에 있는 초록 체크 표시된 줄을 누릅니다.
3. 페이지 맨 아래 **Artifacts** 칸의 **arte-apk** 를 누르면 zip 이 받아집니다.
4. zip 을 풀면 APK 두 개가 나옵니다.
   - `app-release.apk` ← 평소에 쓸 것
   - `app-debug.apk` ← 문제가 생겼을 때 확인용

> 받으려면 깃허브에 로그인되어 있어야 합니다. 로그아웃 상태면 Artifacts 가 안 보입니다.

### 휴대폰에서 바로 받고 싶을 때

깃허브 Artifacts 는 휴대폰 브라우저에서 잘 안 받아집니다.
컴퓨터에서 받은 뒤 카톡 나에게 보내기 · 메일 · USB 중 편한 방법으로 폰에 옮기세요.

---

## 2. 설치하기

1. 폰에서 APK 파일을 누릅니다.
2. "이 출처의 앱 설치" 를 허용하겠냐고 물으면 **허용** 합니다.
   (설정 > 앱 > 특별한 접근 > 알 수 없는 앱 설치 에서도 켤 수 있습니다)
3. **설치** 를 누릅니다. "Play 프로텍트" 경고가 뜨면 **무시하고 설치** 를 고릅니다.
   사내에서 만든 앱이라 플레이스토어에 등록돼 있지 않아 뜨는 안내입니다.

안드로이드 10 이상에서 돌아갑니다.

---

## 3. 앱 쓰기

- 가로로 두면 **사진 · 도면 · 견적** 세 칸이 함께 보입니다. 세로면 위아래로 쌓입니다.
- 도면 항목을 누르면 왼쪽에 사진이 뜨고, 오른쪽 견적 칸이 그 품목으로 넘어갑니다.
- 자필 서명은 손가락과 스타일러스 모두 됩니다.
- 계약서를 만들면 **내 파일 > 다운로드 > 아르떼계약서** 에 엑셀과 이미지가 저장됩니다.

## 4. 내용 고치기

앱 화면 전체가 파일 하나입니다. **`app/src/main/assets/index.html`**
이 파일만 새 걸로 바꾸면 앱이 바뀝니다.

### 깃허브 웹에서 바꾸기 (설치 프로그램 없이)

1. 저장소에서 `app` > `src` > `main` > `assets` 폴더로 들어갑니다.
2. 오른쪽 위 **Add file > Upload files** 를 누르고 새 `index.html` 을 끌어다 놓습니다.
   (이름이 같으면 덮어쓰기 됩니다)
3. 아래 **Commit changes** 를 누릅니다.
4. 바로 **Actions** 에서 빌드가 돌아가고, 3~5분 뒤 새 APK 가 나옵니다.

### 버전 올리기 — 업데이트할 때는 꼭 하세요

`app/build.gradle` 을 열어 아래 두 줄을 고칩니다.

```
versionCode 1      ← 2, 3, 4 … 로 1씩 올립니다 (숫자만)
versionName "1.0"  ← "1.1" 처럼 보기 좋게 (아무 글자나 됩니다)
```

`versionCode` 를 그대로 두면 폰이 "이미 설치된 앱과 같다" 며 업데이트를 거부합니다.
설치할 때 기존 앱 위에 덮어쓰면 저장했던 계약서 파일은 그대로 남습니다.

### 그 밖에 자주 고칠 만한 것

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| 앱 이름 | `app/src/main/res/values/strings.xml` 의 `app_name` |
| 앱 아이콘 | `app/src/main/res/drawable/ic_launcher_fg.xml` |
| 저장 폴더 이름 | `MainActivity.java` 의 `"아르떼계약서"` |

### 빌드가 실패하면

Actions 에서 빨간 X 가 뜬 줄을 누르면 어느 단계에서 멈췄는지 보입니다.
`APK 빌드` 단계를 눌러 빨간 글자를 복사해 두면 원인을 찾기 쉽습니다.
빌드가 안 돌았다면 **Actions > APK 만들기 > Run workflow** 로 직접 돌릴 수 있습니다.
